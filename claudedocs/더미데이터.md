## 실행 순서 요약

1. **독립 테이블**: Company → Stage → CheckList
2. **1차 의존**: User
3. **2차 의존**: Project
4. **3차 의존**: ProjectMember → Memo → Post → ProjectCheckList → ActivityLog
5. **4차 의존**: Comment → Request
6. **5차 의존**: File → Link

## 주의사항

- 이 순서를 **반드시 지켜서** 실행해야 외래키 제약조건 오류가 발생하지 않습니다.
- Password는 BCrypt 해시 예시값입니다. 실제로는 보안을 위해 적절히 암호화해야 합니다.
- IP 주소, 파일 경로 등은 예시이며, 실제 환경에 맞게 수정하세요.
- `NOW()` 함수로 현재 시간을 자동 입력합니다.
