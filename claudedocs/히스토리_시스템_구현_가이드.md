## 시스템 개요

### 목적
게시글(Post)과 관련된 모든 변경 이력을 자동으로 추적하고 기록하는 시스템입니다.

### 추적 대상
- **게시글 (Post)**: UPDATE, DELETE
- **댓글 (Comment)**: UPDATE, DELETE
- **파일 (File)**: CREATE, DELETE
- **링크 (Link)**: CREATE, DELETE

### 핵심 기능
1. ✅ 변경 전/후 데이터 스냅샷 저장
2. ✅ 변경자 정보 및 IP 주소 기록
3. ✅ 비동기 이벤트 기반 처리
4. ✅ 통합 히스토리 조회 API
5. ✅ 시간순 정렬 및 제목 자동 생성

## 아키텍처 설계

### 전체 구조

```
┌─────────────────┐
│   Controller    │ @HistoryLogger 또는 직접 Event 발행
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  AOP Aspect /   │ 변경 전/후 데이터 수집
│  Service Layer  │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ Event Publisher │ HistoryEvent 발행
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ Event Listener  │ @Async 비동기 처리
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ History Entity  │ 히스토리 테이블 저장
└─────────────────┘
```

### 설계 원칙

1. **관심사 분리 (SoC)**: AOP/Event를 사용하여 비즈니스 로직과 히스토리 로직 분리
2. **비동기 처리**: 히스토리 저장이 메인 트랜잭션을 블로킹하지 않음
3. **트랜잭션 독립성**: 히스토리 저장 실패가 원본 트랜잭션에 영향 없음 (`REQUIRES_NEW`)
4. **확장 가능성**: 새로운 추적 대상 추가 시 Event/Listener만 추가

### 1. HistoryPost (게시글 이력)

```java
@Entity
@Getter
@NoArgsConstructor(access = AccessLevel.PROTECTED)
@EntityListeners(AuditingEntityListener.class)
public class HistoryPost {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false)
    private Long originalPostId;  // 원본 게시글 ID

    @Enumerated(EnumType.STRING)
    @Column(nullable = false)
    private ChangeType changeType;  // UPDATE, DELETE

    // 변경 전 데이터
    private String beTitle;
    @Column(columnDefinition = "TEXT")
    private String beContent;
    private String beStageName;
    private Boolean beIsCompleted;

    // 변경 후 데이터 (DELETE시 null)
    private String afTitle;
    @Column(columnDefinition = "TEXT")
    private String afContent;
    private String afStageName;
    private Boolean afIsCompleted;

    // 변경자 정보
    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "changed_by_user_id", nullable = false)
    private User changedByUser;

    @Column(nullable = false)
    private String changeIp;

    @CreatedDate
    @Column(nullable = false, updatable = false)
    private LocalDateTime createdAt;

    @Builder
    public HistoryPost(Long originalPostId, ChangeType changeType,
                      String beTitle, String beContent, String beStageName, Boolean beIsCompleted,
                      String afTitle, String afContent, String afStageName, Boolean afIsCompleted,
                      User changedByUser, String changeIp) {
        this.originalPostId = originalPostId;
        this.changeType = changeType;
        this.beTitle = beTitle;
        this.beContent = beContent;
        this.beStageName = beStageName;
        this.beIsCompleted = beIsCompleted;
        this.afTitle = afTitle;
        this.afContent = afContent;
        this.afStageName = afStageName;
        this.afIsCompleted = afIsCompleted;
        this.changedByUser = changedByUser;
        this.changeIp = changeIp;
    }

    // 스냅샷 생성 팩토리 메서드
    public static HistoryPost createSnapshot(Post beforePost, Post afterPost,
                                             ChangeType changeType, User changedByUser, String changeIp) {
        return HistoryPost.builder()
                .originalPostId(beforePost.getId())
                .changeType(changeType)
                // Before data
                .beTitle(beforePost.getTitle())
                .beContent(beforePost.getContent())
                .beStageName(beforePost.getStage() != null ? beforePost.getStage().getName() : null)
                .beIsCompleted(beforePost.getIsCompleted())
                // After data (null if DELETE)
                .afTitle(afterPost != null ? afterPost.getTitle() : null)
                .afContent(afterPost != null ? afterPost.getContent() : null)
                .afStageName(afterPost != null && afterPost.getStage() != null ? afterPost.getStage().getName() : null)
                .afIsCompleted(afterPost != null ? afterPost.getIsCompleted() : null)
                .changedByUser(changedByUser)
                .changeIp(changeIp)
                .build();
    }
}
```

#### HistoryPostEventListener
```java
@Component
@RequiredArgsConstructor
@Slf4j
public class HistoryPostEventListener {

    private final HistoryPostRepository historyPostRepository;
    private final UserRepository userRepository;

    @Async
    @EventListener
    @Transactional(propagation = Propagation.REQUIRES_NEW)
    public void handleHistoryPostEvent(HistoryPostEvent event) {
        try {
            User changedByUser = userRepository.findById(event.getChangedByUserId())
                    .orElseThrow(() -> new IllegalArgumentException("User not found"));

            HistoryPost historyPost = HistoryPost.createSnapshot(
                    event.getBeforePost(),
                    event.getAfterPost(),
                    event.getChangeType(),
                    changedByUser,
                    event.getChangeIp()
            );

            historyPostRepository.save(historyPost);
            log.info("HistoryPost saved: postId={}, changeType={}",
                    event.getBeforePost().getId(), event.getChangeType());

        } catch (Exception e) {
            log.error("Failed to save HistoryPost", e);
            // 히스토리 저장 실패가 원본 트랜잭션에 영향 없음
        }
    }
}
```

#### 핵심 포인트
- `@Async`: 비동기 처리로 성능 영향 최소화
- `@Transactional(propagation = Propagation.REQUIRES_NEW)`: 독립된 트랜잭션
- `try-catch`: 히스토리 저장 실패가 메인 로직에 영향 없음

## 히스토리 추적 구현

### 1. AOP 기반 추적 (Post, Comment UPDATE/DELETE)

#### @HistoryLogger 어노테이션
```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface HistoryLogger {
    ChangeType changeType();
    String targetType() default "Post";
}
```

#### HistoryLogAspect
```java
@Aspect
@Component
@RequiredArgsConstructor
@Slf4j
public class HistoryLogAspect {

    private final PostRepository postRepository;
    private final CommentRepository commentRepository;
    private final FileRepository fileRepository;
    private final ApplicationEventPublisher eventPublisher;

    @Pointcut("@annotation(org.etmetmy.bn_server.global.aop.HistoryLogger)")
    public void historyLoggerPointcut() {}

    @Around("historyLoggerPointcut() && @annotation(historyLogger)")
    public Object saveHistoryLog(ProceedingJoinPoint joinPoint, HistoryLogger historyLogger)
            throws Throwable {

        // 1. 변경 전 데이터 조회
        if ("Post".equals(historyLogger.targetType())) {
            return handlePostHistory(joinPoint, historyLogger);
        } else if ("Comment".equals(historyLogger.targetType())) {
            return handleCommentHistory(joinPoint, historyLogger);
        }

        return joinPoint.proceed();
    }

    private Object handlePostHistory(ProceedingJoinPoint joinPoint, HistoryLogger historyLogger)
            throws Throwable {
        Long postId = extractPostId(joinPoint);
        Post originalPost = postRepository.findById(postId)
                .orElseThrow(() -> new IllegalArgumentException("Post not found"));

        // 2. 실제 메서드 실행
        Object result = joinPoint.proceed();

        // 3. 변경 후 데이터 조회 (UPDATE인 경우)
        Post updatedPost = null;
        if (historyLogger.changeType() == ChangeType.UPDATE) {
            updatedPost = postRepository.findById(postId).orElse(null);
        }

        // 4. IP 및 사용자 정보 추출
        HttpServletRequest request = ((ServletRequestAttributes)
                RequestContextHolder.getRequestAttributes()).getRequest();

        Long userId = SessionUtil.getLoginUserId(request.getSession());
        String clientIp = IpAddressUtil.getClientIp(request);

        // 5. 이벤트 발행
        eventPublisher.publishEvent(
                new HistoryPostEvent(originalPost, updatedPost,
                        historyLogger.changeType(), userId, clientIp)
        );

        return result;
    }

    private Long extractPostId(ProceedingJoinPoint joinPoint) {
        Object[] args = joinPoint.getArgs();
        for (Object arg : args) {
            if (arg instanceof Long) {
                return (Long) arg;
            }
        }
        throw new IllegalArgumentException("postId를 찾을 수 없습니다");
    }
}
```

### 2. Service 레이어 직접 발행 (File, Link CREATE/DELETE)

#### PostServiceImpl - 파일/링크 삭제 시 히스토리 발행
```java
@Service
@RequiredArgsConstructor
@Transactional
public class PostServiceImpl implements PostService {

    private final ApplicationEventPublisher eventPublisher;

    @Override
    public PostCreateResponse updatePost(Long postId, PostUpdateRequest requestDto, Long loginUserId) {
        // ... 게시글 업데이트 로직

        // 삭제된 파일에 대한 히스토리 발행
        List<File> filesToDelete = post.getFiles().stream()
                .filter(file -> !requestDto.getFileIds().contains(file.getId()))
                .toList();

        String clientIp = getClientIp();

        for (File file : filesToDelete) {
            file.softDelete(loginUserId);

            // 파일 히스토리 이벤트 발행
            eventPublisher.publishEvent(
                    new HistoryFileEvent(file, ChangeType.DELETE, loginUserId, clientIp)
            );
        }

        // 삭제된 링크에 대한 히스토리 발행
        List<Link> existingLinks = post.getLinks();
        for (Link link : existingLinks) {
            eventPublisher.publishEvent(
                    new HistoryLinkEvent(link, ChangeType.DELETE, loginUserId, clientIp)
            );
        }
        linkRepository.deleteAll(existingLinks);

        return new PostCreateResponse(post.getId());
    }

    private String getClientIp() {
        try {
            ServletRequestAttributes attributes = (ServletRequestAttributes)
                    RequestContextHolder.getRequestAttributes();
            if (attributes != null) {
                HttpServletRequest request = attributes.getRequest();
                return IpAddressUtil.getClientIp(request);
            }
        } catch (Exception e) {
            // RequestContext가 없는 경우
        }
        return null;
    }
}
```

#### HistoryItemResponse
```java
@Getter
@Builder
@NoArgsConstructor
@AllArgsConstructor
public class HistoryItemResponse {

    private String title;                  // "홍길동님이 2025-12-18 15:30에 게시글을 수정했습니다"
    private String targetType;             // POST, COMMENT, FILE, LINK
    private ChangeType changeType;         // CREATE, UPDATE, DELETE
    private LocalDateTime changedAt;       // 변경 시간
    private String changedByUserName;      // 변경한 사람 이름
    private String changeIp;               // 변경 IP
    private Object details;                // 상세 정보 (타입별 Detail 객체)

    /**
     * 히스토리 제목 생성: "누가, 언제, 무엇을, 어떻게"
     */
    public static String createTitle(String userName, LocalDateTime changedAt,
                                     String targetType, ChangeType changeType) {
        String action = getActionText(targetType, changeType);
        String timeStr = changedAt.toString().replace("T", " ");
        return String.format("%s님이 %s에 %s", userName, timeStr, action);
    }

    private static String getActionText(String targetType, ChangeType changeType) {
        String target = switch (targetType) {
            case "POST" -> "게시글을";
            case "COMMENT" -> "댓글을";
            case "FILE" -> "파일을";
            case "LINK" -> "링크를";
            default -> "항목을";
        };

        String action = switch (changeType) {
            case CREATE -> "추가했습니다";
            case UPDATE -> "수정했습니다";
            case DELETE -> "삭제했습니다";
        };

        return target + " " + action;
    }
}
```

### HistoryServiceImpl

```java
@Service
@RequiredArgsConstructor
@Transactional(readOnly = true)
public class HistoryServiceImpl implements HistoryService {

    private final PostRepository postRepository;
    private final HistoryPostRepository historyPostRepository;
    private final HistoryCommentRepository historyCommentRepository;
    private final HistoryFileRepository historyFileRepository;
    private final HistoryLinkRepository historyLinkRepository;

    @Override
    public HistoryListResponse getAllHistory(Long postId) {
        // 1. 게시글 존재 확인
        Post post = postRepository.findById(postId)
                .orElseThrow(BoardNotFoundException::new);

        List<HistoryItemResponse> allHistories = new ArrayList<>();

        // 2. 각 히스토리 테이블에서 데이터 조회
        List<HistoryPost> postHistories = historyPostRepository
                .findByOriginalPostIdOrderByCreatedAtDesc(postId);
        List<HistoryComment> commentHistories = historyCommentRepository
                .findByPostIdOrderByCreatedAtDesc(postId);
        List<HistoryFile> fileHistories = historyFileRepository
                .findByPostIdOrderByCreatedAtDesc(postId);
        List<HistoryLink> linkHistories = historyLinkRepository
                .findByPostIdOrderByCreatedAtDesc(postId);

        // 3. HistoryPost → HistoryItemResponse 변환
        for (HistoryPost historyPost : postHistories) {
            HistoryPostDetail detail = HistoryPostDetail.builder()
                    .beTitle(historyPost.getBeTitle())
                    .beContent(historyPost.getBeContent())
                    .beStageName(historyPost.getBeStageName())
                    .beIsCompleted(historyPost.getBeIsCompleted())
                    .afTitle(historyPost.getAfTitle())
                    .afContent(historyPost.getAfContent())
                    .afStageName(historyPost.getAfStageName())
                    .afIsCompleted(historyPost.getAfIsCompleted())
                    .build();

            String title = HistoryItemResponse.createTitle(
                    historyPost.getChangedByUser().getName(),
                    historyPost.getCreatedAt(),
                    "POST",
                    historyPost.getChangeType()
            );

            allHistories.add(HistoryItemResponse.builder()
                    .title(title)
                    .targetType("POST")
                    .changeType(historyPost.getChangeType())
                    .changedAt(historyPost.getCreatedAt())
                    .changedByUserName(historyPost.getChangedByUser().getName())
                    .changeIp(historyPost.getChangeIp())
                    .details(detail)
                    .build());
        }

        // 4. 댓글, 파일, 링크도 동일한 방식으로 변환
        // (코드 생략 - 위와 동일한 패턴)

        // 5. 시간순 정렬 (최신순)
        allHistories.sort(Comparator.comparing(HistoryItemResponse::getChangedAt).reversed());

        // 6. 응답 생성
        return HistoryListResponse.builder()
                .postId(postId)
                .totalCount(allHistories.size())
                .histories(allHistories)
                .build();
    }
}
```

### 2. extractFileId NoSuchElementException

#### 증상
```
NoSuchElementException: No value present
at HistoryLogAspect.handleFileHistory(HistoryLogAspect.java:141)
```

#### 원인
`FileController.deletePostFiles` 메서드가 3개의 Long 파라미터(projectId, postId, fileId)를 가지는데,
`extractFileId()` 메서드가 첫 번째 Long을 추출하여 `projectId`를 `fileId`로 잘못 인식

#### 해결책
Controller에서 `@HistoryLogger` 어노테이션을 제거하고, Service 레이어에서 직접 Event 발행
```java
// ❌ 잘못된 방법
@DeleteMapping("/posts/{postId}/files/{fileId}")
@HistoryLogger(changeType = ChangeType.DELETE, targetType = "File")
public void deletePostFiles(@PathVariable Long projectId, @PathVariable Long postId, @PathVariable Long fileId) { }

// ✅ 올바른 방법
@DeleteMapping("/posts/{postId}/files/{fileId}")
public void deletePostFiles(@PathVariable Long projectId, @PathVariable Long postId, @PathVariable Long fileId) {
    fileService.deletePostFiles(projectId, postId, fileId, loginUserId);
}

// FileServiceImpl
public void deletePostFiles(...) {
    File file = fileRepository.findById(fileId).orElseThrow();
    file.softDelete(loginUserId);

    // 직접 이벤트 발행
    eventPublisher.publishEvent(new HistoryFileEvent(file, ChangeType.DELETE, loginUserId, clientIp));
}
```

```java
@Override
public void deletePostFiles(Long projectId, Long postId, Long fileId, Long loginUserId) {
```

## 핵심 장점

### 1. 관심사 분리 (Separation of Concerns)
- 비즈니스 로직과 히스토리 로직이 완전히 분리
- Controller/Service는 핵심 기능에만 집중

### 2. 비동기 처리
- `@Async`를 통해 히스토리 저장이 메인 응답 시간에 영향 없음
- 대용량 히스토리 데이터 처리 시 성능 유지

### 3. 트랜잭션 독립성
- `REQUIRES_NEW` 전파 수준으로 히스토리 저장 실패가 메인 트랜잭션에 영향 없음
- 시스템 안정성 향상

### 4. 확장 가능성
- 새로운 추적 대상 추가 시 Event/Listener만 추가
- 기존 코드 수정 최소화

### 5. 통합 조회
- 4개 히스토리 테이블을 하나의 API로 통합 조회
- 시간순 정렬로 변경 흐름 파악 용이
